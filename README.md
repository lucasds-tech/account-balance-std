# Santander Account Balance API

REST API for Santander account balance inquiry, built with Java and Spring Boot. The application processes financial transactions via AWS SQS and exposes the latest account balance through REST.

## 🚧 Project Status

**Under development.**

New features, integrations, and automated tests are currently being implemented.

## 🛠 Technologies and Tools

* Java 21
* Spring Boot
* Spring Web
* Spring Data JPA
* PostgreSQL
* Flyway
* AWS SQS
* OpenAPI / Swagger
* JUnit 5
* Mockito

* Testcontainers
